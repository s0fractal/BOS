# Archived Gemini nodes prototype

This directory preserves the first BOS graph experiment.

It was removed from the active surface when BOS-0001 introduced:

- stable IDs independent of filenames;
- closed semantic kinds and payload schemas;
- typed relations with referential integrity;
- orthogonal status axes;
- context cuts and per-actor trajectories;
- an explicit freedom-versus-authority boundary.

These files are historical design input only. They MUST NOT be loaded as
normative BOS-0001 atoms or mixed into active graph validation.

The two empty bootstrap files from the prototype,
`Assets@v0.myc.md` and `value@v0.myc.md`, were not archived because they
contained no information.
