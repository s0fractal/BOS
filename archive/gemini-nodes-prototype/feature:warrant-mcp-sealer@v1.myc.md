# Warrant MCP Sealer

Sealer для Model Context Protocol, що працює безпосередньо в контурі виклику (tool-calls), а не постфактум.
Він записує та печатає рішення, коли агент звертається до tool, створюючи warrant-запис (і evidence pack).
